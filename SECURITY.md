## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please use one of the following methods:

1. **GitHub Private Vulnerability Reporting** – Use the [Security tab](../../security/advisories/new) to submit a private vulnerability report.
2. **Email** – Contact the repository maintainers directly via email.

### What to include in your report

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant screenshots, logs, or proof-of-concept code
- Suggested remediation steps (if known)

### Response timeline

- You will receive an acknowledgement within **48 hours**.
- We aim to provide a resolution or mitigation plan within **7 days**.
- We will keep you updated on progress throughout the process.

### Disclosure policy

We follow a coordinated disclosure process. Please allow us reasonable time to address the vulnerability before any public disclosure.

Thank you for helping to keep this project secure.
